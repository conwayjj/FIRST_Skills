Overview

Arm Feedforward

The same vertical linear actuator and 1–3 link rotational chain from Inverse Kinematics — but now every link has real mass, gravity is on, and your step(dt) no longer commands a target angle or extension directly. It commands raw motor power, -1..1, the way a real motor controller does — and gravity never stops pulling, so power = 0 does not mean "hold still."

Objective

Hold the target pose with feedforward + feedback

Click anywhere in the workspace to instantly solve a target pose (the same CCD solve from the Inverse Kinematics module runs once, offline, and fills in the target extension and joint angle sliders on the left) — or set those sliders by hand. Then write a step(dt) that gets there and holds it. A pure proportional controller sags below target the same way it did in PIDF Control — gravity here is worse, because it changes with pose instead of staying constant, so the feedforward term has to be recomputed every frame from the arm's actual mass, link length, and current angle. getGravityTorque(i) gives you exactly that number, live.

Reference

step(dt) API

setLinearPower(power)
Prismatic joint motor output, -1..1.
getExtension() / getExtVelocity()
Current extension (m) and velocity (m/s).
setPower(i, power)
Rotational joint i motor output, -1..1.
getAngle(i) / getVelocity(i)
Current angle (°) and angular velocity (°/s) of joint i.
getGravityTorque(i)
Live gravity torque on joint i (N·m) from every link beyond it — positive means gravity is trying to increase the angle. Divide by the motor's stall torque (negated) for a holding feedforward term.
getMass(i) / getLinearMass()
Segment mass (kg) / fixed carriage mass (kg).
stopSim()
Call once every error is small.
println(...)
Write a line to the console panel below the editor.
endX, endY
Current end-effector position (m).
targetExtension, targetAngles[]
The pose set on the left (or solved from your last workspace click) — extension in m, angles in °.
extError, angleErrors[]
target - current, already shortest-path wrapped for angles.
numRotJoints, lengths[], masses[]
Configured joint count, link lengths (m), and link masses (kg).
maxExtension, linMass, gravity
Max extension (m), fixed carriage mass (kg), and gravity (m/s²).
